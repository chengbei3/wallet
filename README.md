# 钱包

本地记账与资产管理 Android 应用。数据保存在手机本地，不依赖服务器，适合个人日常收支、多账户余额和人民币 / 美元资产汇总。

当前版本：`1.2.2`（`minSdk 24`）

## 功能概览

底部三个页面：**记账**、**资产**、**我的**。可左右滑动切换。

### 记账

- 记录支出 / 收入，支持分类、账户、备注，以及「不计入收支」（不影响本月统计）。
- 自定义数字键盘输入金额，金额符号随所选账户币种变化（人民币 `¥` / 美元 `$`）。
- 分类会记住上次使用的付款账户。例如交通用微信支付后，下次再选交通会自动切到微信。
- 账单可点击修改，也可删除；删除后会回滚对应账户余额。
- 月度收入 / 支出汇总，以及按月、按年的分类统计。
- 可设置启动时自动打开「添加记账」。
- 记账页支持双击进入「只看壁纸」模式，再双击恢复界面。

### 资产

- 管理多个账户（现金、银行卡、支付宝、微信、美元账户等），支持人民币和美元。
- 总资产按设定汇率折合人民币显示。
- 点击账户名查看该账户流水；点击金额可直接改余额。改余额时可选是否生成「余额调整」账单（计入流水，不计入收支统计）。
- 账户互转：只调整余额，不出现在记账列表，也不计入收支。
  - 同币种：转出金额 + 可选手续费。
  - 美元 ↔ 人民币：需填写汇率，手续费从转出账户扣除。
  - 互转记录可在对应账户流水中查看。

### 我的

- 昵称、头像（可预览、更换）。
- 美元兑人民币汇率。
- 每日 10:00 推送当前总资产（可开关；开机后会重新调度）。
- 字体大小：标准 / 较大 / 特大。
- 各页独立壁纸，以及壁纸遮罩、记账页遮罩、卡片透明度、顶栏 / 底栏透明度。
- 桌面图标：默认绿、森林、海洋、暖阳，或自定义图片。
- 导入 / 导出 JSON 备份（账户 + 账单）。互转、分类绑账户等字段会随备份一起保存。

## 默认数据

首次安装会预置账户：

| 账户 | 币种 | 初始余额 |
| --- | --- | --- |
| 现金 | 人民币 | 2000 |
| 银行卡 | 人民币 | 15000 |
| 支付宝 | 人民币 | 3500 |
| 微信 | 人民币 | 1200 |
| 美元账户 | 美元 | 500 |

支出分类：餐饮、交通、购物、娱乐、居住、医疗、教育、其他。  
收入分类：工资、奖金、投资、兼职、其他。

## 技术说明

- Kotlin + Jetpack Compose + Material 3
- 本地存储：`SharedPreferences` + JSON
- 架构：`Compose UI` → `WalletViewModel` → `WalletRepository`
- 通知：WorkManager 定时任务 + 开机广播
- 包名：`com.wallet`

数据只存在本机。卸载应用或清除应用数据会丢失未备份的记录，请先在「我的 → 数据管理」中导出。

## 构建

使用 Android Studio 打开本项目，或在项目根目录执行：

```bash
./gradlew :app:assembleDebug
```

产物位于 `app/build/outputs/apk/debug/`。
